# Project Summary

End-to-End Cloud Data Platform is a master's-level student data engineering portfolio project.

## Main Goal

To practise building a modern cloud data platform with ingestion, orchestration, transformation, modelling, quality checks, monitoring, CI/CD and dashboard delivery.

## Main Components

- API / streaming ingestion design
- Airflow orchestration
- Databricks-style Spark transformations
- Bronze, Silver and Gold layers
- dbt analytics models
- Snowflake-style serving layer
- Power BI dashboard mockups
- Streamlit live demo
- GitHub Actions CI/CD
- Terraform infrastructure plan
- Data quality checks
- Monitoring documentation
